# Ημερολόγιο — GlenApps

Ημερολόγιο ραντεβού για κάθε επάγγελμα: ημέρα / εβδομάδα / μήνας / λίστα, πάγια ραντεβού, ελεύθερα κενά, προσωπικό με χρώματα, αργίες, δεσμεύσεις, λίστα αναμονής, υπενθυμίσεις με μήνυμα, αρχείο για το ημερολόγιο του κινητού και PDF.

Προέλευση: το ημερολόγιο «Ραντεβού» του LUMIO, απομονωμένο και γενικό.

## Αρχεία
- `index.html` — η σελίδα και τα στυλ
- `imerologio.js` — **το κοινό κομμάτι του ημερολογίου** (μπαίνει και σε άλλες εφαρμογές· στην αρχή του γράφει τι πρέπει να του δίνει η εφαρμογή που το φιλοξενεί)
- `app.js` — η αυτόνομη εφαρμογή γύρω του: πρόσωπα, ρυθμίσεις, επάγγελμα, αντίγραφα, αναβάθμιση
- `epaggelmata.js` — τα επαγγέλματα: λέξεις (πελάτης / ασθενής / μαθητής…), ειδικότητες προσωπικού, διάρκεια, πάγια ή μία φορά. Νέο επάγγελμα = μία γραμμή.
- `version.json`, `sw.js`, `manifest.json`, εικονίδια

## Νέα έκδοση
Αλλάζει ο αριθμός σε τρία σημεία: `index.html` (app-version), `version.json`, `sw.js` (VER).

Τα δεδομένα μένουν μόνο στη συσκευή του χρήστη· αντίγραφα στον κοινό φάκελο των εφαρμογών (υποφάκελος `Imerologio`).
